Team Introduction

Sevenfold is a solo project for CSC 4370/6370 at Georgia State University.

Project Leader and sole team member

Ibrahim "Bee" Mackey

Fourth-year Computer Science student who designed, built, tested, and documented Sevenfold, a dice-based card gaming hub made with HTML and CSS only.

Responsibilities

  • Design: game rules, wireframes, colour and type system
  • Build: semantic HTML pages and the shared CSS system
  • QA: responsive, keyboard, reduced-motion, and link checks
  • Project management: Kanban board, daily journal, time tracking, and submission
